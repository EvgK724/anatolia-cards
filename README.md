# Малая Азия. В один взгляд

[Открыть приложение](https://evgk724.github.io/anatolia-cards/).

15 полноэкранных карточек о древних городах и святилищах. Дидимы, Эфес, Милет, Сарды, Афродисиада, Пергам и Троя. Короткие авторские тексты, крупные числа и семь тёмных однотонных фонов.

## Использование

Листайте влево или вправо, нажимайте стрелки или используйте клавиатуру. Кнопка счётчика открывает обзор, источники и раздел «На телефон». Позиция сохраняется на этом устройстве.

При первом открытии с интернетом приложение сохраняет карточки, краткую справку, шрифты и иконки. Перед отключением сети дождитесь сообщения «15 карточек сохранены на этом устройстве» в разделе «На телефон». Для чтения внешних страниц источников интернет нужен. Очистка данных или автоматическое удаление хранилища браузером удаляет локальную копию.

Новая версия загружается целиком и проверяется по SHA-256. В разделе «На телефон» появится кнопка «Обновить, сохранив место». Обновление применяется по нажатию; текущая карточка сохраняется.

На iPhone откройте сайт в Safari, выберите «Поделиться» → «На экран Домой». QR открывает адрес, установка выполняется вручную. Реальная установка, физический виброотклик и Safari/iOS требуют отдельной проверки на устройстве. Вибрация вызывается только при поддержке браузером; Safari её не предоставляет через Vibration API.

## Исходники и проверка

Приложение находится в `dist/`. Внешние CDN для чтения не используются. Источники описаны в `SOURCES.md` и доступны в справке приложения. Шрифты Golos Text распространяются по SIL OFL 1.1; copyright и полный текст лицензии сохранены в `dist/fonts/OFL.txt`.

```sh
python3 scripts/build-offline.py
python3 validate.py
node tests/offline-worker.mjs
```

Тест Service Worker использует изолированное хранилище в памяти и не заменяет реальный сетевой прогон в браузере.

## GitHub Pages

Workflow проверяет исходники при push в main. Публикация предусмотрена только для общедоступного репозитория с разрешённым GitHub Pages. В приватном репозитории задача публикации пропускается. Публичная аудитория этого репозитория и приложения подтверждена владельцем.

Публикуется только каталог `dist/`. Все пути, идентификатор PWA, стартовый адрес и область Service Worker относительные, поэтому приложение поддерживает адрес вида `/anatolia-cards/`.
